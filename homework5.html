Exercise 1: Welford's Recurrence Formulas

Derivation

Welford's algorithm computes the mean and variance incrementally, avoiding numerical instability and requiring only one pass through the data.

Mean Recurrence (Knuth's Formula)

Given data points x₁, x₂, ..., xₙ, the mean Mₖ after k observations:

M₁ = x₁

Mₖ = Mₖ₋₁ + (xₖ - Mₖ₋₁) / k

Sum of Squares Recurrence

The sum of squared deviations SSₖ = Σᵢ₌₁ᵏ (xᵢ - Mₖ)²:

SS₁ = 0

SSₖ = SSₖ₋₁ + (xₖ - Mₖ₋₁) × (xₖ - Mₖ)

Variance

Once SSₖ is computed, the variance is simply:

Var = SSₖ / k

Key Properties

  • Single pass: Only requires one iteration through the data
  • O(1) memory: Only stores running values (n, mean, SS)
  • Numerically stable: Avoids catastrophic cancellation
  • Online: Can update statistics as new data arrives

Core Implementation (3 lines)

    mean = mean + (x - mean) / n
    SS = SS + (x - mean_prev) × (x - mean)

Exercise 2: Sampling Mean and Variance

Problem Setup

Consider a scenario where:

  • m hackers each attempt to penetrate n systems
  • Each penetration attempt receives a score from 0 to 10, drawn from a fixed probability distribution
  • The theoretical mean and variance of this distribution are μ and σ²
  • Each hacker receives n scores (one per system), forming a trajectory

Analysis Procedure

  1. For each hacker, use Welford's algorithm to compute the sampling mean and sampling variance of their n scores
  2. Across the m hackers, compute the average of the sampling means and the average of the sampling variances
  3. Compare these averages with the theoretical values μ and σ²
  4. Repeat the experiment for different values of n to observe how sample size affects variability

Theoretical Expectations

Law of Large Numbers

The average of the sampling means should converge to the population mean:

E[X̄] = μ

The average of the sampling variances should converge to the population variance:

E[S²] ≈ σ²

Central Limit Theorem

The distribution of sampling means should be approximately normal with:

X̄ ~ N(μ, σ²/n)

The standard deviation of sampling means should decrease as:

SD(X̄) = σ/√n

Implications for Inferential Statistics

  • Unbiasedness: Sample statistics are good estimators of population parameters
  • Consistency: Estimates improve as sample size increases
  • Efficiency: Larger samples yield more precise estimates (lower variance)
  • Normality: Sampling distributions approach normality, enabling hypothesis testing and confidence intervals

Single Simulation

Run a single simulation with m hackers and n systems to observe the relationship between sampling statistics and population parameters.

Available Distributions

Uniform Distribution

Mean: μ = (a + b + c) / 3 ≈ 5.0

Properties: Symmetric, peaked at mode, simple model

Convergence Study: Effect of Sample Size n

Investigate how increasing the number of systems n affects the variability of sampling statistics.

What to Observe

Decreasing Variability

As n increases, the standard deviation of sampling means should decrease according to:

SD(X̄) = σ/√n

This means:

  • Doubling n reduces variability by √2 ≈ 1.41
  • 10× more data reduces variability by √10 ≈ 3.16
  • Larger samples produce more consistent estimates

Practical Implications

  • Sample size matters: More systems tested → more reliable assessment of hacker skill
  • Diminishing returns: Variance decreases as 1/n, so doubling precision requires 4× more data
  • Trade-offs: Balance between estimation precision and cost/time of data collection
  • Confidence intervals: Larger n → narrower intervals → more precise inferences

Expected Plot Behavior

The convergence plot should show:

  • Observed std dev of sampling means (blue points) decreasing with n
  • Theoretical curve σ/√n (red dashed line) matching observations

Conclusions

1. Law of Large Numbers

  • The average of sampling means converges to the population mean μ as the number of hackers increases
  • The average of sampling variances converges to the population variance σ²
  • This validates that sample statistics are unbiased estimators of population parameters

2. Central Limit Theorem

  • The distribution of sampling means is approximately normal, even when the underlying distribution is not
  • The variability of sampling means decreases as σ/√n with increasing sample size
  • This enables inferential statistics: we can construct confidence intervals and perform hypothesis tests

3. Effect of Sample Size

  • Larger samples (n) → more consistent estimates → lower variance of sampling statistics
  • The relationship SD(X̄) = σ/√n shows diminishing returns: quadrupling sample size only halves the standard error
  • In the hacker scenario: testing more systems gives better estimates of each hacker's skill level

4. Practical Significance

  • Reliability: Sample-based estimates are trustworthy when sample sizes are adequate
  • Precision: We can quantify estimation uncertainty using σ/√n
  • Efficiency: Welford's algorithm computes statistics in a single pass with O(1) memory
  • Decision-making: Understanding sampling variability helps set appropriate sample sizes for desired precision

5. Why These Results Matter in Inferential Statistics

These simulations demonstrate the foundational principles that justify inferential statistics:

  • We can use sample data to make reliable inferences about populations
  • We can quantify the uncertainty in our estimates
  • We can determine how much data we need for desired precision
  • The normal distribution emerges naturally from aggregating random variables, enabling standard statistical tests

Cybersecurity Interpretation

Hacker Skill Assessment

In this model, each hacker's sampling mean represents their estimated skill level based on n penetration attempts. Key insights:

  • Individual assessment: Each hacker's mean score estimates their true skill μ
  • Confidence in assessment: With n systems tested, the standard error is σ/√n
  • Example: If σ = 1.5 and n = 100, then SE = 1.5/10 = 0.15, meaning skill estimates are typically within ±0.3 of true skill (95% CI)
  • Ranking hackers: Larger n makes rankings more reliable by reducing noise in estimates

System Vulnerability Assessment

Alternatively, if we fix the attacker and vary systems, the scores reflect system vulnerabilities:

  • Each system receives a vulnerability score from 0 to 10
  • The sampling mean estimates the average vulnerability across n systems
  • The sampling variance indicates heterogeneity of vulnerabilities
  • Testing more systems (larger n) gives more precise estimates of average vulnerability

Resource Allocation

Understanding the σ/√n relationship informs security testing strategies:

  • Budget constraints: If testing is expensive, choose n to balance cost and precision
  • Risk tolerance: Critical systems may require larger n for tighter confidence intervals
  • Adaptive testing: Start with small n, expand if initial variance is too high
