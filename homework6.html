Exercise 1: Riemann and Lebesgue Integration

Theoretical Background

Riemann Integration

The Riemann integral partitions the domain [a, b] into n subintervals:

∫ₐᵇ f(x) dx ≈ Σᵢ f(xᵢ) Δx

where Δx = (b - a) / n and xᵢ are sample points in each subinterval.

Lebesgue Integration

The Lebesgue integral partitions the range of f into levels yⱼ and measures the preimage:

∫ₐᵇ f(x) dx ≈ Σⱼ yⱼ · μ({x : yⱼ ≤ f(x) < yⱼ₊₁})

where μ denotes the measure (length) of the set of x-values where f takes values in [yⱼ, yⱼ₊₁).

Key Differences

  • Riemann: Partitions domain uniformly, samples function values
  • Lebesgue: Partitions range, measures preimages (inverse images)
  • For Riemann-integrable functions: Both approaches converge to the same value
  • For pathological functions: Lebesgue may integrate functions Riemann cannot

Numerical Implementation

Riemann approach: Direct evaluation at grid points

Lebesgue approach: For each range level, find measure of preimage by scanning domain and counting/measuring where function falls in that range

Test Functions

Smooth Functions

  • f(x) = sin(x) on [0, π]: Exact = 2
  • f(x) = x² on [0, 1]: Exact = 1/3
  • f(x) = sin(x)/x on [0, π]: Exact ≈ 1.3179 (Si(π))

Discontinuous Functions

  • Step function: f(x) = 1 if x < 0.5, 3 if x ≥ 0.5 on [0, 1]: Exact = 2
  • Indicator function: f(x) = 1 if x < 0.5, 0 if x ≥ 0.5 on [0, 1]: Exact = 0.5

Functions with Singularities

  • f(x) = 1/√x on (0, 1]: Exact = 2 (improper integral)
  • f(x) = |x - 0.5| on [0, 1]: Exact = 0.25

Pathological Functions

  • Dirichlet function: f(x) = 1 if x rational, 0 if irrational on [0, 1]
  • Thomae's function: f(x) = 1/q if x = p/q in lowest terms, 0 if irrational on [0, 1]

Expected Behavior

Smooth Functions

  • Riemann: O(1/n²) convergence rate for smooth functions (midpoint rule)
  • Lebesgue: Similar convergence, but may be slower due to preimage computation overhead
  • Both methods: Converge to the same value

Discontinuous Functions

  • Step functions: Riemann converges quickly despite discontinuity
  • Lebesgue: May handle discontinuities more naturally by grouping similar values
  • Convergence rate: O(1/n) at discontinuity points

Pathological Functions

  • Dirichlet function: Not Riemann-integrable, but Lebesgue-integrable (integral = 0)
  • Thomae's function: Riemann-integrable (integral = 0) but numerical methods struggle
  • Dense discontinuities: Numerical approximations may fail to capture true behavior

Computational Efficiency

  • Riemann: O(n) complexity, very fast
  • Lebesgue: O(n × m) where m is range partitions, slower but more general
  • Adaptive methods: Can improve both approaches by refining partitions where needed

Exercise 2: Normal CDF Computation

Mathematical Background

Standard Normal CDF

The cumulative distribution function of the standard normal distribution N(0,1) is:

Φ(x) = (1/√(2π)) ∫₋∞ˣ exp(-t²/2) dt

Why No Elementary Form?

Liouville's theorem (1835) states that the antiderivative of exp(-t²) cannot be expressed in terms of elementary functions (polynomials, exponentials, logarithms, trigonometric functions, and their compositions).

Intuitively: elementary functions have "simple" antiderivatives, but exp(-t²) requires fundamentally new functions.

The Error Function

The error function is defined as:

erf(x) = (2/√π) ∫₀ˣ exp(-t²) dt

This is a special function - not elementary, but well-studied and tabulated.

Relationship to Normal CDF

The normal CDF can be expressed exactly using erf:

Φ(x) = (1/2)[1 + erf(x/√2)]

This is an exact analytical representation, but erf itself must be computed numerically.

Why Numerical Methods Are Still Needed

  • The error function is defined via an integral, which must be computed numerically
  • No finite formula exists in terms of elementary operations
  • We must use approximations: numerical integration, series expansions, or rational approximations

Numerical Approaches

1. Numerical Integration (Trapezoidal/Simpson)

Directly integrate (1/√(2π)) exp(-t²/2) from -∞ to x using quadrature rules.

  • Trapezoidal rule: Simple, O(1/n²) convergence
  • Simpson's rule: More accurate, O(1/n⁴) convergence
  • Adaptive quadrature: Refine where integrand changes rapidly

2. Series Expansion of erf

Taylor series for erf around x = 0:

erf(x) = (2/√π) Σ_{n=0}^∞ (-1)ⁿ x^(2n+1) / (n! (2n+1))

  • Works well for |x| < 1
  • Fast convergence near origin
  • Requires many terms for large |x|

3. Asymptotic Expansion (large x)

For large |x|, use continued fraction or asymptotic series:

1 - Φ(x) ≈ φ(x)/x [1 - 1/x² + 3/x⁴ - ...]

  • Efficient for |x| > 3
  • Complements series expansion

4. Rational Approximations

Use polynomial ratios fitted to minimize error (e.g., Abramowitz & Stegun approximations).

Understanding Liouville's Theorem

What Are Elementary Functions?

Elementary functions are built from:

  • Constants and the variable x
  • Arithmetic operations: +, −, ×, ÷
  • Exponentials and logarithms: exp(x), ln(x)
  • Trigonometric functions: sin(x), cos(x), tan(x), etc.
  • Inverse trigonometric functions: arcsin(x), arctan(x), etc.
  • Finite compositions and combinations of the above

What Liouville's Theorem Says

Liouville's theorem (differential algebra, 1835) provides a criterion for when an integral has an elementary antiderivative. For many functions, including exp(-x²), the theorem proves no elementary antiderivative exists.

Consequence: We cannot write ∫ exp(-x²) dx using any combination of elementary functions. This is a fundamental mathematical limitation, not a lack of cleverness.

Why This Matters for the Normal CDF

  • The standard normal PDF is φ(x) = (1/√(2π)) exp(-x²/2)
  • The CDF is Φ(x) = ∫₋∞ˣ φ(t) dt = ∫₋∞ˣ exp(-t²/2) dt
  • By Liouville's theorem, Φ(x) cannot be expressed using elementary functions
  • We must introduce a special function (erf) to represent it analytically
  • Even with erf, we need numerical methods for practical computation

Special Functions as Extensions

Special functions like erf, Bessel functions, gamma function, etc., extend the class of functions we can work with. They are:

  • Defined precisely (usually via integrals or differential equations)
  • Well-studied with known properties
  • Tabulated and implemented in numerical libraries
  • Essential for solving real-world problems in statistics, physics, engineering

Why Numerical Methods Are Necessary

Even though Φ(x) = ½[1 + erf(x/√2)] is an exact formula:

  • erf is defined as an integral: erf(x) = (2/√π) ∫₀ˣ exp(-t²) dt
  • We cannot evaluate this integral symbolically
  • For any practical computation, we must approximate the integral numerically
  • Series expansions, quadrature rules, and rational approximations are all numerical methods
  • The "exact" representation using erf is conceptual; computation is always approximate

Conclusions

Exercise 1: Riemann vs Lebesgue Integration

  • Convergence: For Riemann-integrable functions, both methods converge to the same value
  • Efficiency: Riemann approach is typically faster (O(n) vs O(n×m)), better suited for smooth functions
  • Discontinuities: Lebesgue approach may handle pathological cases more gracefully by grouping similar function values
  • Pathological functions: Dirichlet function is Lebesgue-integrable but not Riemann-integrable, though numerical approximations struggle with both
  • Practical use: Riemann-style methods dominate in numerical analysis due to efficiency; Lebesgue theory is essential for mathematical foundations

Exercise 2: Normal CDF Computation

  • Elementary functions insufficient: Liouville's theorem proves ∫ exp(-x²) dx has no elementary antiderivative
  • Special functions needed: Error function erf provides exact analytical representation but must be computed numerically
  • Multiple approaches: Numerical integration (Simpson/trapezoidal), series expansion, rational approximations all work
  • Trade-offs: Series fast for small |x|, asymptotic for large |x|, rational approximations balance accuracy/speed
  • Practical implementation: Modern libraries use piecewise methods (different approaches for different x ranges)

Broader Implications

  • Many real-world problems require numerical methods because exact solutions don't exist
  • Understanding convergence rates helps choose appropriate precision/performance trade-offs
  • Special functions extend our mathematical toolkit beyond elementary functions
  • Numerical analysis bridges the gap between mathematical theory and practical computation

Statistical Interpretation

Integration in Statistics

Integration is fundamental to probability and statistics:

  • Probability: P(a < X < b) = ∫ₐᵇ f(x) dx where f is the PDF
  • Expectation: E[X] = ∫ x f(x) dx
  • Variance: Var(X) = ∫ (x - μ)² f(x) dx
  • Numerical methods: Essential when analytical solutions unavailable

The Normal Distribution's Ubiquity

The normal CDF appears everywhere in statistics:

  • Hypothesis testing: Z-tests, t-tests (approximate normal for large n)
  • Confidence intervals: Constructed using normal quantiles
  • Central Limit Theorem: Sample means approach normal distribution
  • Error analysis: Measurement errors often assumed normal

Why Efficient CDF Computation Matters

In cybersecurity and data analysis:

  • Anomaly detection: Compute p-values to identify outliers (requires Φ evaluation)
  • Risk assessment: Quantify probability of extreme events (tail probabilities)
  • Monte Carlo simulations: Generate normal random variables (inverse CDF method)
  • Performance: Statistical software evaluates Φ millions of times; efficiency critical

Practical Example: Anomaly Detection

Suppose network traffic volumes are normally distributed with μ = 1000 GB, σ = 150 GB:

  • Observed traffic: 1500 GB
  • Standardize: z = (1500 - 1000) / 150 ≈ 3.33
  • Compute p-value: P(X > 1500) = 1 - Φ(3.33) ≈ 0.0004
  • Conclusion: This is a 1-in-2500 event, likely anomalous
  • Fast, accurate Φ computation enables real-time detection
